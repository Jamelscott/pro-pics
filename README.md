# Pro Pics

A cross-platform photo workspace for capturing, marking up, organizing, and sharing project photos. Built with Expo (SDK 57), React Native, Expo Router, and Supabase.

## Features

- **Auth** – Supabase sign-in gate; the app shows the login screen until a session exists.
- **Home** – storage usage, cloud storage breakdown, recent activity, and quick re-entry into recent projects.
- **Camera** – in-app capture with markup overlay and a storage-limit warning.
- **Projects** – projects and folders, search, move media, photo editor, and sharing.
- **Settings** – account and theme (light/dark/system) preferences.
- **Storage** – media is stored on-device and/or in a Supabase Storage bucket (`media`).

## Getting started

### Prerequisites

- Node.js (LTS) and npm
- Xcode (iOS) and/or Android Studio (Android)
- A Supabase project

### Setup

```sh
npm install
cp .env.example .env
```

Fill in `.env` with your Supabase project values:

```sh
EXPO_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

Only `EXPO_PUBLIC_*` values are bundled into the client, so never put secrets in them. Apply the SQL in `supabase/migrations/` to your Supabase project (for example with the Supabase CLI: `supabase db push`).

### Run

The app uses native modules that are not in Expo Go, so run a development build:

```sh
npm run ios       # expo run:ios
npm run android   # expo run:android
npm run start     # start the dev server for an installed dev build
npm run web       # web (limited native feature support)
```

`ios/` and `android/` are generated by Expo (Continuous Native Generation) and are gitignored. Configure native behavior in `app.json` and config plugins rather than editing them by hand.

## Project structure

```
src/
  app/            Expo Router routes: root layout, (tabs)/ (index, camera, projects), settings
  components/     UI grouped by feature: auth, camera, home, projects, ui
  constants/      Theme colors
  context/        UserContext (auth session) and ThemeContext
  hooks/          Color-scheme and theming hooks
  lib/            Supabase client, auth, projects, storage, media upload, local media
  utils/          Shared helpers
supabase/
  migrations/     Database schema and row-level security policies
assets/           App icons, splash, and tab bar artwork
```

## Quality checks

```sh
npm run lint
npm run typecheck
```

Install or update native modules with `npx expo install <package>` so versions match the project's Expo SDK.

## Testing a production-like build

```sh
npx expo run:ios --configuration Release --device
npx expo run:android --variant release
```

To distribute to testers, build with EAS (`npx eas-cli@latest build`) and submit to TestFlight / Google Play internal testing with `eas submit`.
